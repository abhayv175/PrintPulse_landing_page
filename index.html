Engineering Architecture

Distributed Cloud & Edge Sync

A hardened, multi-tenant system with strict tenant directory isolation, bidirectional WebSocket event dispatching, and Docker Compose deployment.

1. Edge Clients
Customer Web & Vendor App
HTML5 • Vanilla JS • Flutter Android

Zero-install mobile browser upload, canvas rendering, and Flutter tablet client with hardware spooling.

2. Edge Gateway
Reverse Proxy & SSL
jh0yc.aiccloud.online (Port 80/443)

Terminates TLS, dispatches REST traffic, and proxies persistent WSS duplex event channels.

3. ASGI Core
FastAPI Backend (Python 3.12)
pypdf • WebSocket Bus • UPI Engine

Multi-file document ingress, async page inspection, NPCI intent generation, and UDP beacon (port 8002).

4. Storage & Spool
Persistence & Hardware
/uploads/{id}/ • Printing.layoutPdf()

Strict tenant directory isolation, local transactional order state, and direct USB/Wi-Fi hardware spooling.

End-to-End Distributed Request Lifecycle

1 Scan & Upload: Customer scans desk QR code and streams PDF to cloud gateway.
2 Edge Proxy: Cloud reverse proxy streams multipart payload to FastAPI ASGI core.
3 Compute Cost: Async pypdf inspects page counts and calculates B&W/Color rates in <20ms.
4 UPI Intent: Core formats NPCI URI (upi://pay?...) with vendor VPA and order token.
5 Dynamic QR: Portal displays dynamic QR code with one-tap deep-links for GPay/PhonePe/Paytm.
6 Claim Payment: Customer completes UPI transfer and submits 12-digit UTR confirmation claim.
7 WebSocket Push: Cloud backend relays real-time event (< 50ms) to vendor Android tablet.
8 Audio Alert: Vendor client plays new_job.mp3 chime and displays incoming job in Live Queue.
9 1-Tap Spool: Vendor taps VERIFY & PRINT; job dispatches to hardware and server auto-purges file.

Core API & WebSocket Endpoints

Standardized REST endpoints and duplex WebSocket event buses powering the PrintPulse ecosystem. Click any endpoint to copy.

Method Endpoint Description
GET /shop/{vendor_id} Serves customer upload web portal configured for specific vendor pricing and VPA.
POST /api/documents/batch-upload Multi-file multipart upload with async page count inspection and sheet calculation.
POST /api/orders/create Generates order token, pricing summary, and NPCI UPI URI string.
POST /api/orders/{id}/claim-payment Customer submits 12-digit UTR ref or one-tap payment claim.
POST /api/orders/{id}/verify-payment Vendor or webhook marks order verified and dispatches to hardware queue.
GET /api/vendor/{vendor_id}/stats Vendor dashboard session revenue, prints completed, and totals.
GET /api/vendor/{vendor_id}/history Retrieves completed and rejected order archive for vendor.
DELETE /api/vendor/{vendor_id}/history Clears vendor order history from database with permanent wipe.
WSS /ws/vendor/{vendor_id} Real-time bi-directional order stream for vendor Android tablet.
WSS /ws/orders/{order_id} Dedicated WebSocket channel for live checkout status updates.

PrintPulse utilizes the National Payments Corporation of India (NPCI) UPI deep-link standard. It dynamically formats a payment string directly to the vendor's Virtual Payment Address (VPA).
